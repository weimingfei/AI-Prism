# 学习生命周期

1. 用户创建或进入练习会话。
2. 用户上传资料或笔记。
3. 后端解析资料：
   - PDF 文本层快速提取；
   - 质量检测；
   - 低质量资料调用 MinerU 增强解析；
   - Markdown/JSON 归一化；
   - 分块、Embedding 和 RAG 入库。
4. AI 生成知识点大纲和知识点清单。
5. 前端展示清单，用户选择一个知识点。
6. 用户用文字或语音讲解。
7. 后端恢复可写运行态，校验当前题，调用评分 Agent，并推进状态机。
8. AI 根据评分和追问上限决定继续追问或关闭当前知识点。
9. 用户可以继续练习、跳过剩余知识点或结束学习。
10. 后端生成报告、知识卡片和复习计划。
